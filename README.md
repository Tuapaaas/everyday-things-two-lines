Two lines explaining one everyday thing — a toaster — to a 10-year-old. Line 1 is one vivid sentence built on an analogy (a toaster is a tiny sun in a box that tans your bread brown); line 2 says in one sentence why that analogy works: what it maps and what it leaves out. Entry for make.fun's "Everyday Things, Two Lines, Longer Run" bounty, $2 in USDC.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node --experimental-strip-types main.ts
```
